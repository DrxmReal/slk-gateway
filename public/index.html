from openai import OpenAI

# Khởi tạo client trỏ đến Vercel API Gateway của bạn
client = OpenAI(
    base_url="$GATEWAY_URL",  # Ví dụ: https://your-project.vercel.app/v1
    api_key="dummy-key"       # Hoặc CUSTOM_ACCESS_KEY nếu bạn bật bảo mật
)

# Gửi yêu cầu Chat Completion
response = client.chat.completions.create(
    model="DeepSeek-V4-Flash",  # hoặc 'auto', 'glm-5.3', 'kimi-k3'
    messages=[
        {"role": "user", "content": "Xin chào, hãy giới thiệu về bạn."}
    ],
    stream=True  # Hỗ trợ SSE Streaming mượt mà
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: '$GATEWAY_URL', // Ví dụ: https://your-project.vercel.app/v1
  apiKey: 'dummy-key',     // Hoặc CUSTOM_ACCESS_KEY
});

async function main() {
  const stream = await openai.chat.completions.create({
    model: 'auto',
    messages: [{ role: 'user', content: 'Giải thích cơ chế Proxy API?' }],
    stream: true,
  });

  for await (const chunk of stream) {
    process.stdout.write(chunk.choices[0]?.delta?.content || '');
  }
}

main();

Hướng dẫn triển khai lên Vercel trong 3 phút

Trang web và API Gateway này được thiết kế tương thích 100% với Vercel Serverless & Edge Functions. Bạn có thể host hoàn toàn miễn phí!

1 Cách 1: Deploy trực tiếp bằng Vercel CLI (Nhanh nhất)

Mở terminal tại thư mục dự án và chạy các lệnh sau: 

# 1. Đăng nhập Vercel (nếu chưa đăng nhập)
npx vercel login

# 2. Triển khai dự án lên Vercel
npx vercel --prod
💡 Vercel sẽ tự động phát hiện tệp vercel.json và thư mục api/ và cấp cho bạn một tên miền miễn phí dạng https://your-project.vercel.app.
2 Cách 2: Đẩy lên GitHub rồi kết nối Vercel
  1. Tạo một repository mới trên GitHub (public hoặc private).
  2. Đẩy mã nguồn thư mục này lên GitHub:
    git init
    git add .
    git commit -m "Initial commit AI Gateway"
    git branch -M main
    git remote add origin https://github.com/<user>/<repo>.git
    git push -u origin main
  3. Truy cập vercel.com/new và chọn Import repository của bạn.
  4. Nhấn Deploy. Vercel sẽ build và cung cấp link trang web ngay lập tức!

Cấu hình Biến môi trường (Environment Variables) trên Vercel

Trong bảng điều khiển Vercel > Dự án của bạn > Settings > Environment Variables, bạn có thể thiết lập:

Tên biến (Key) Giá trị mặc định Ý nghĩa
UPSTREAM_BASE_URL https://api.hcnsec.cn/v1 Địa chỉ API gốc cần proxy
UPSTREAM_API_KEY sk-y0tm0bCPJ... Secret Key của API gốc (được bảo mật phía máy chủ)
CUSTOM_ACCESS_KEY (Để trống là công khai) Mật khẩu bảo vệ Gateway nếu bạn chỉ muốn cấp cho người có mã này dùng
